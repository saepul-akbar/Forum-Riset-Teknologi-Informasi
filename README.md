# Forum Riset dan Teknologi Informasi

Repository ini berisi kumpulan praktik, tugas, dan project pembelajaran yang saya kerjakan dalam Forum Riset dan Teknologi Informasi. Repo ini digunakan sebagai tempat dokumentasi perkembangan belajar, mulai dari dasar pemrograman web, pemrograman berorientasi objek, hingga project web menggunakan framework modern.

## Tentang Repository

Repository ini dibuat untuk menyimpan dan mengelola berbagai latihan serta project secara terstruktur. Fokus utama dari repository ini adalah membangun fondasi pemrograman, memahami alur kerja pengembangan project, dan membiasakan penggunaan Git serta GitHub dalam proses belajar.
